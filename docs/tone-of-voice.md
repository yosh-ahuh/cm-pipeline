# Spot トーンオブボイス

Spot の言葉の指針。UI文言・エラー・空状態・トースト・メール・通知など、ユーザーが読むすべての言葉に適用する。
デザイントークン（[../spot-app/styles/tokens.css](../spot-app/styles/tokens.css)）が「見た目」を定めるように、この文書は「言葉」を定める。
関連: [design-system.md §8 ライティング指針](./design-system.md)（マイクロコピー規則の要約）。

対象ユーザー: **ITリテラシーが高くない日本のマーケティング担当者**。コンセプトは「**選ぶだけ**でAI広告動画をつくれる」。
→ 言葉の役割は、**不安を減らし、次の一歩をやさしく示すこと**。

---

## 1. ブランドパーソナリティ ——「頼れる相棒」🤝

Spot は、隣に座ってくれる**頼れる相棒**のように話す。

| 軸 | そうである | そうではない |
|---|---|---|
| 関係 | 対等な目線・伴走する | 上から教える・先生ぶる |
| 気持ち | やさしい・前向き | 冷たい・事務的すぎる |
| ペース | 急かさない・待てる | あおる・焦らせる |
| 態度 | 素直・誠実 | 大げさ・お世辞っぽい |
| 難しさ | かみ砕く | 専門用語で煙に巻く |

**一言でいうと**: 「むずかしいことは Spot がやるので、あなたは選ぶだけで大丈夫」と、落ち着いて言える相棒。

---

## 2. 声のトーン原則

1. **敬体（です・ます）で統一。** タメ口も過度な堅さも使わない。
2. **主役は「あなた」、Spot は黒子。** 一人称「私たち」は基本使わない。機能ではなく、ユーザーができることを書く。
3. **成果物の言葉で話す。** 「生成」より「つくる」。クレジットは「＝CM◯本」で具体化。
4. **短く、やさしく。** 一文は短く。むずかしい語はそのつど言い換える。
5. **急かさない・責めない。** 待ち時間は不安を減らす言葉を。エラーはユーザーのせいにしない。
6. **次の一歩を必ず示す。** 行き止まりの文で終えない（空状態・エラーは特に）。
7. **絵文字は控えめに、意味があるときだけ。** 完了の喜びなど。乱用しない。乱発は"軽さ"に転ぶ。

## 3. Do / Don't（実例）

| 場面 | ❌ 避ける | ✅ Spotらしい |
|---|---|---|
| エラー | エラーが発生しました。 | うまく送信できませんでした。通信環境を確認して、もう一度お試しください。 |
| 認証失敗 | 認証情報が無効です。 | メールアドレスまたはパスワードが正しくありません。 |
| 空状態 | データがありません。 | まだCMはありません。最初の1本を、いくつか選ぶだけでつくれます。 |
| ボタン | OK ／ 送信 | クレジットを追加 ／ このプランにする |
| 生成中 | 処理中... | AIがCMをつくっています。数分お待ちください。 |
| 完了 | 正常に完了しました。 | できました！ CMを9本つくりました。 |
| 権限なし | 権限がありません。 | この操作はオーナーのみ可能です。オーナーにご相談ください。 |
| 専門語 | レンダリングに失敗 | 動画の書き出しに失敗しました。もう一度お試しください。 |
| あおり | 今すぐ購入しないと損！ | クレジットが少なくなっています。追加すると続けてつくれます。 |

**原則**: エラーは「①何が起きたか ＋ ②次にどうするか」。空状態は「①今の状態 ＋ ②始め方の誘い」。

## 4. 語彙集（使う語 / 避ける語）

| 使う ✅ | 避ける ❌ | 理由 |
|---|---|---|
| つくる／作成する | 生成する | 「選ぶだけでつくれる」体験に合わせる |
| CM／動画 | コンテンツ、アセット | 具体的な成果物の言葉 |
| クレジット（＝CM◯本） | ポイント、トークン | 用語を統一。必ず「＝CM◯本」を添える |
| 認証番号 | OTP、ワンタイムパスワード | 略語・英語を避ける |
| サインイン／サインアウト | ログイン/ログアウト（※混在させない） | アプリ内で統一（現状サインイン系） |
| 書き出し／ダウンロード | エクスポート、レンダリング | 日常語に |
| オーナー／メンバー／閲覧のみ | 管理者、admin | 役割をやさしい語で |
| 設定 | コンフィグ、環境設定 | シンプルに |

- 「**スポット**」という語は使わない（サービス名 Spot と紛れる。単位は「本／件」）。
- 半角英字ブランド名は **Spot**（先頭大文字）。
- 迷ったら「その言葉、うちの親でも分かる？」で判断する。

## 5. 場面別テンプレート

### ボタン（動詞から・何が起きるか）
- ✅「クレジットを追加」「このプランにする」「CMをつくる」「もう一度お試しください」
- 破壊的操作は結果を明示：「このCMを削除」（❌「削除」だけにしない）

### エラー（責めない・次の手を示す）
- 型: `〜できませんでした。＜原因や確認点＞。もう一度お試しください。`
- 例:「うまく送信できませんでした。通信環境を確認して、もう一度お試しください。」
- 未知のエラーでも汎用でやさしく:「問題が発生しました。もう一度お試しください。」

### 空状態（誘いで終える）
- 型: `まだ＜対象＞はありません。＜始め方＞。`
- 例:「まだCMはありません。「新規CM」から、選ぶだけでつくれます。」

### ローディング / 送信中（不安を消す）
- 短い操作:「メールを送信中…」「確認中…」
- 時間のかかる生成:「AIがCMをつくっています。数分お待ちください。」
- 進捗があれば添える:「AIが制作中です… 3/9 完了・数分お待ちください」

### トースト（結果を一言で）
- 成功:「できました！」「共有リンクをコピーしました」
- 完了数を添える:「CMを9本つくりました。」

### 確認ダイアログ（判断材料を渡す）
- 何がどうなるかを先に:「このCMを削除すると、元に戻せません。削除しますか？」

### メール（ブランド版テンプレートと揃える）
- 件名は名詞で短く:「パスワードの再設定」「認証番号」
- 本文はやさしい一段落＋明確なボタン。参照: [../spot-app/supabase/email-templates/](../spot-app/supabase/email-templates/)

## 6. 表記ルール

- **敬体**（です・ます）。命令形は避け、依頼形に（「お試しください」）。
- **数字には単位と補足**：「残り 42 本」「クレジット（＝CM◯本）」。半角数字＋前後に半角スペース（和文中も可読性優先）。
- **三点リーダは `…`**（`...` ではなく）。待ち状態の語尾に。
- **感嘆符・絵文字は 1文に1つまで**、喜びの場面に限る。エラー・警告では使わない。
- **英語UI**でも人格は同じ（頼れる相棒）。丁寧だがフレンドリー、命令形は最小限、"you"主語、専門用語を避ける。
  - 例: ❌ "Invalid credentials." → ✅ "Email or password is incorrect."
  - 例: ❌ "Processing…" → ✅ "Sending email…" / "Creating your ad…"
