# quality-rules.md — 検品チェックリスト

`cm review` が視覚LLMに注入する検品仕様。各 live-action カットのスチル（および動画化後の
フレーム）を検査し、NG項目があれば理由付きでリトライ指示を出す。

**原則**: 破綻はスチル段階で潰す（動画化前に）。動画化してからの手戻りはコストが桁違い。

---

## A. 破綻検出（最優先・自動リトライ対象）

| # | 項目 | 検出内容 | 頻度 |
|---|---|---|---|
| A1 | **手・指** | 指の本数（5本か）、関節の破綻、余分な指 | ★AI最大の弱点 |
| A2 | **小道具の形状** | カメラ・機器類の本体/レンズ比率の破綻 | 高 |
| A3 | **光のフレア** | 顔・耳への不自然な光の塊/レンズフレア | 中 |
| A4 | **読める文字** | 小道具（バインダー背表紙等）の化け日本語 | 高 |
| A5 | **顔の一貫性** | カット間で顔・髪型・服装が変わっていないか | 高 |
| A6 | **コラージュ化** | アスペクト変更編集時の2枚組/分割パネル化 | 縦生成時 |

A1〜A4 の修正は nano-banana edit で該当部分だけ差し替え（他は変えない）。

## B. AI感の抑制（演出・後処理で対応）

| # | 項目 | 対策 |
|---|---|---|
| B1 | 色が綺麗すぎる | グレードB（放送用クール：影が青緑・周辺減光・トーンカーブ） |
| B2 | 完璧に静止した画 | 動的グレイン + 手持ち風マイクロドリフト |
| B3 | 世界が死んでいる | LIVING WORLD 指示（文脈でON/OFF） |
| B4 | 顔がぬるっと・無表情 | 顔の微細表情を明示振り付け。ダメなら構図を寄せて明るく |
| B5 | 解像度が甘い | Veoは1080p必須。ソーススチルを2048pxで作り直す |
| B6 | 背景が走行/スクロール | 停車等の文脈では窓外を完全静止（数値検証: 窓領域の時間差分） |

## C. 日本考証

- 右ハンドル / 日本の軽バン・オフィス備品 / 日本人の実写

## D. ブランド・法務

| # | 項目 | 検出内容 / 対応 |
|---|---|---|
| D1 | ロゴ・商品名の正確さ | ウォーターマークは全画面固定。商品名の読みは `brand.pronunciation` を必ず適用 |
| D2 | 参考素材と使用可素材の区別 | **公式サウンドロゴ等の「参考のみ」を本番に使わない** |
| D3 | **実在人物との類似** | 生成した人物が著名人・実在人物に似ていないか（`compliance.likeness_check`）。似ている場合は顔を再生成 |
| D4 | 景表法: 偽UI禁止 | `type: ui` は提供スクショ / コード描画のみ。生成モデルに UI を描かせない（`compliance.real_ui_only`） |
| D5 | 数値訴求の根拠 | 「月40時間」等の数値は `compliance.claims_evidence` に根拠があるものだけ。注記（※）を自動付与 |
| D6 | AI利用の開示 | 末尾にAI利用表記を焼き込む（JIAA 自主開示ガイドライン 2026-04）。`compliance.ai_disclosure` |
| D7 | コンテンツ認証 | C2PA で生成モデル・編集履歴を書き出しに記録。モデル側の透かし（SynthID 等）は保持 |
| D8 | 権利の明確なモデルのみ | 配役表のモデルは商用利用可・学習データが明示されたものに限る（Seedance 2.0 の Hollywood 反発、Sora 終了を踏まえ供給先を固定しない） |

競合調査（research/competitive-research-2026-09.md）より: Icon（2026年3月閉鎖）は「音声品質・没個性・不安定なUI」で沈んだ。
D1 の発音辞書と A/B の検品ループは、その弱点への直接回答であり、営業資料でも前面に出す。

## プロセス教訓（今日の反省を仕様化）

- **素材差し替えの検証は最終レンダリングの実フレームで行う**。素材単体のフレーム確認では、
  コンポジションが古い素材を参照し続ける「差し替え漏れ」を見逃す（スプラッシュ等のシーケンス
  オフセットにも注意）。
- **Python文字列の複数行 replace は不一致でも無言で失敗する**。置換後は必ず grep + 実フレーム確認。
- **fal残高切れ（TOP_UP）は反映ラグで一時的なことがある**。数回リトライ（backoff）で回復する場合あり。
- **20MB超の書き出しはRemote Control転送でタイムアウトしがち**。crf30-33の軽量版を作って送る。
