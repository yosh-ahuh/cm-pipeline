# SPOT 競合調査（2026年9月10日時点）

対象: SPOT（B2B マーケチーム向け「選ぶだけ」AI コマーシャル制作スタジオ。実写＋実プロダクトUI＋NA＋BGM を生成し、3パターン×3フォーマットを当日納品。日英対応）

## 結論（TL;DR）

1. **SPOT と完全に同じ座標にいるプレイヤーはまだいない。** 海外の AI 広告 SaaS（Creatify / Arcads / HeyGen）は「AIアバター＋UGC風」「EC の商品URL→広告」に寄っており、**実在するプロダクトUIを合成した B2B SaaS/アプリ向け CM** を主戦場にしているものはない。国内 SaaS（リチカ / Video BRAIN）は**素材を組み立てるテンプレート型**で、映像そのものを生成しない。
2. **最大の脅威は競合 SaaS ではなくプラットフォーム内蔵ツール**（TikTok Symphony / Meta Advantage+ & Muse Video / Google Asset Studio & Pomelli）。無料で「URL や画像から動画広告」を作れるため、Creatify 自身も「最大の競争脅威」と公言している。SPOT は媒体横断・ブランド管理・実UI という「媒体側が提供しないもの」で差を出す必要がある。
3. **国内では CyberAgent が最も近い動き**。「ブランド300万動画」（3本で300万円・1.5〜2週間）と「2026年中にプロンプト不要の動画広告完全自動生成」を掲げる。ただし代理店モデル（運用受託とセット）であり、事業会社が自走できる SaaS ではない。ここに SPOT の空白がある。
4. **価格帯の空白**: 海外 SaaS は月 $39〜$410、国内の AI CM 制作サービスは 1本 50万円〜300万円。「1本 数万円・当日・ブランド確認済み」という SaaS と制作会社の中間帯は空いている。
5. **Icon の失敗（2026年3月に閉鎖）が教訓**: $12M のドメイン購入とブランディングよりも「音声品質」「生成物が没個性」「UIが不安定」で顧客が離れた。SPOT の「検品ループ」「発音辞書」「実UI」はまさにこの弱点を突く設計で、訴求の中心に据える価値がある。

## 主要競合 詳細

### Creatify（米国）— 最も近い海外競合
- 位置づけ: 商品 URL → 広告動画。AI アクター 300〜1,500体、テンプレ、Performance Agent（Meta/Google/TikTok/AppLovin へ直接出稿・最適化）、競合広告トラッカー、MCP 連携。
- 実績: ARR $9M（2025年5月時点、Sacra 推定）、累計調達 $23M（Series A $15.5M）。「1M マーケター / 10,000 チーム」を主張。
- 料金: Starter $39/月（100クレジット）、Pro $99/月（300〜5,000クレジット、5席・5ブランド）、Enterprise（Done-for-You Studio、白ラベル、API）。年契約で最大50%オフ。
- 弱点: アバターのリアルさは Arcads に劣る。クレジット失効。分析は専業に劣る。**実アプリ UI は「URL をスクレイプして画像を拾う」レベルで、実画面を CM に織り込む工程はない。**
- 対 SPOT: ターゲットは D2C/EC/アプリ運用者。B2B SaaS のブランド CM ではなく「量産テスト」。日本語・国内法務は弱い。

### Arcads（仏）— AI アクター品質のリーダー
- 位置づけ: 台本ファースト・フック駆動の UGC 風広告。アクター 1,000体以上、Seedance 2.5 / Sora 2 Pro / Kling をルーティング、30言語ローカライズ、ワークフローキャンバス。
- 実績: ARR $15M（2026年）。資金は情報が割れている（ブートストラップ説 vs Eurazeo 主導 $16M シード）。「$1B モバイルアプリスタジオ」を顧客に持つ。
- 料金: 約 $110/月（10本）〜 $220（20本）〜 $410（カスタムアバター）。価格非公開・無料トライアルなし。
- 弱点: 商品 URL 取り込みなし、分析なし、**製品デモは外部 B-roll が必要**。高単価で量産テストに不向き。
- 対 SPOT: 「人が喋る」広告に特化。プロダクト UI を主役にした CM は作れない。

### HeyGen（米国）— アバター＋Video Agent
- Avatar IV、Video Agent（台本→広告を自動生成、生成 B-roll 付き）、175言語リップシンク、URL→動画。$24〜29/月から。エンタープライズ向け SSO/ブランドキット。
- 対 SPOT: 汎用アバター動画基盤。広告フォーマット設計・媒体別の勝ちパターンは持たない。

### Pencil / AdCreative.ai / Omneky — 「予測・量産」系
- Pencil: ROAS 事前予測（$1B 超の広告費データ）。Meta 直結が最強、TikTok/Google は手動。$14/月〜。
- AdCreative.ai: 静止画バナー量産＋スコアリング。
- Omneky: Brand LLM でブランド分析→出稿までのエージェント型。エンタープライズは広告費連動課金。
- 対 SPOT: 静止画・パフォーマンス予測が中心。CM 品質の動画生成ではない。「予測スコア」は SPOT が将来取り込む価値がある機能。

### MakeUGC / Poolday / Pippit / Zeely — 低価格 UGC 量産
- MakeUGC $49〜119/月。Poolday はモバイルアプリ向け A/B 量産（上位 $2,199/月）。Pippit は ByteDance 製で Seedance 2.0 搭載、$24/月〜。
- 対 SPOT: 単価競争の底。SPOT はここと戦わない。

### 媒体内蔵ツール（無料）
- TikTok Symphony: ブリーフ→動画。制作時間 70% 削減を主張。広告アカウントがあれば無料。
- Meta: Muse Image（2026年7月）→ Muse Video を Advantage+ Creative に順次統合予定。
- Google: Asset Studio（Gemini+Veo、URL/画像から動画、ワンクリック A/B）、Pomelli（Business DNA でブランド抽出、Animate は Veo 3.1、170か国以上）。
- 対 SPOT: 単一媒体・単一フォーマット・ブランド統制が弱い。**媒体横断で「同じ企画を 9ファイル」に展開し、承認フロー付きで回せる**のは SPOT 側の優位。

### 国内: リチカクラウド
- 「2,000社の支援ノウハウ」を掲げる広告/SNS 内製化 AI。URL から商品分析→ペルソナ→動画・LP・検索広告コピー。2026年4月に「LP と画像から 10 本一括生成」を追加。
- **方式は素材組み合わせ（実写生成ではない）**。著作権リスクを抑える設計を訴求。
- 対 SPOT: 同じ「内製化」訴求で顧客層が重なる（マーケ担当・代理店）。差は「映像そのものを生成するか」。SPOT の方が上流（CM 品質）、リチカは運用バナー・動画の量産。

### 国内: Video BRAIN（OPEN8）
- 法人動画編集クラウド 5年連続シェア No.1、累計 1,100社（日経225 の過半）。テンプレ 3,500種、画面収録、分析。年契約・本数無制限。料金は資料請求。
- 対 SPOT: 用途は研修・社内・採用が中心。広告 CM 品質ではない。ただし「画面収録」を持ち、エンプラ営業網が強い。

### 国内: AvaMo（ベクトル）/ 極予測AI（CyberAgent）
- AvaMo: AI タレント 120体、¥3,900〜¥100,000/月。PR 会社ベクトル傘下。
- 極予測AI/TD: 効果予測＋コピー・画像生成。ChatGPT 広告のパイロットにも対応（2026年6月）。動画完全自動生成は 2026年中の目標。**代理店の運用とセット**。

### 国内: 制作サービス型
- CyberAgent「日本一のAI動画を追求するセンター」（2025年10月）: 「ブランド300万動画」＝3本 300万円、1.5〜2週間、まず YouTube 広告から。
- ムービーインパクト Studio PRO: 50万円（税別）〜、「Human Finish」（色補正・音声処理）を差別化。格安 AI サービスの「修正回数制限・AI 出力そのまま」を批判。
- ブルーアール「AI CM」（taziku と技術提携）、AI/AD MAKERS（JPC、モデル 3万円〜）。
- 対 SPOT: SPOT の「1/400・当日」はこの層に対して桁違い。ただし彼らの「人の仕上げ」「炎上防止チェック」は購買側の不安に応えている。SPOT は「検品ループ＋ブランドキット＋発音辞書」で同じ不安に SaaS として答える必要がある。

## SPOT の差別化ポイント（競合が持たないもの）

1. **実プロダクト UI の合成**: Creatify は URL スクレイプ、Arcads は外部 B-roll 頼み。「偽 UI を作らない」は B2B SaaS/アプリの法務・ブランド担当に直接刺さる。
2. **プロンプト不要の「選ぶだけ」**: 媒体×業種×ターゲットの選択肢に勝ちパターンを埋め込む。CA も「プロンプト不要」を 2026年の目標に掲げており、方向性は正しい。
3. **3パターン×3フォーマット一括**: 媒体内蔵ツールは単一媒体。媒体横断の A/B 素材供給。
4. **日英・国内法務**: 発音辞書、景表法配慮、JIAA の AI 利用自主開示ガイドライン（2026年4月）への対応。海外勢が最も弱い部分。
5. **検品ループ（視覚 LLM）**: Icon が「没個性・AI 感」で沈んだ点への直接回答。

## 脅威と弱点（正直に）

- **媒体内蔵ツールの無料化**: 「まず無料で試す」層を吸われる。SPOT はブランド統制・複数媒体・承認フローで「チームの標準ツール」を狙う。
- **モデル供給リスク**: Sora は 2026年3月に終了、Seedance 2.0 は Hollywood 反発で世界展開一時停止。SPOT の配役表（Kling/Veo 振り分け）は強みだが、依存先の変化に追随し続けるコストがかかる。
- **CyberAgent の完全自動化**: 2026年中に実現すれば「代理店に任せれば無料で付いてくる」形で事業会社に届く。SPOT は「内製・自走・当日」で先に定着させる必要がある。
- **実績・信頼**: Creatify は「10,000チーム」、Video BRAIN は「1,100社」。SPOT の「+120 teams」表記は裏付けが必要（現状の実案件はミライ工事 1件）。
- **アバター品質**: Arcads/HeyGen は「人が喋る」品質で数年先行。SPOT は「人物より UI とシーン」で勝負し、人物訴求では戦わない選択が合理的。

## 推奨アクション

1. **ポジショニングの言い直し**: 「AI 動画広告ツール」ではなく「**実UI を織り込む B2B SaaS/アプリ専用の AI CM スタジオ**」と明言し、Creatify/Arcads（UGC・EC）と同じ棚に置かれないようにする。
2. **比較表を営業資料化**: 本レポートの「実UI / プロンプト不要 / 3×3 / 日英 / 検品」の 5 軸で ○×表を作り、ランディングの Why SPOT 直下に置く。
3. **価格の初期設定**: 空白帯（1本 3〜15万円相当）を狙い、席課金＋クレジットで「月 ¥5〜15万・CM 3〜5本」から。Enterprise は承認フロー・SSO・API で上乗せ（Creatify の Enterprise 構成を参考）。
4. **実績の確保**: 「+120 teams」を降ろすか、パイロット 5〜10 社を早期に集めて置き換える。制作サービス型（¥50万〜）から流れてくる案件が最初の顧客候補。
5. **法務を武器に**: JIAA ガイドライン準拠の「AI 利用開示」テンプレ、SynthID 等の電子透かし、肖像権チェックを機能として明示。国内エンプラの導入審査で差になる。
6. **媒体連携のロードマップ**: Creatify の Performance Agent、Pencil の予測スコアは次の競争軸。まずは Meta/Google/TikTok への書き出し仕様準拠、次に出稿連携。
